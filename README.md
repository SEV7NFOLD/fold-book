# Fold Book — repository README (updated)

This repository now includes a script to generate CSV files you can import into Glide to create a mobile-friendly student app.

Quick steps
1. Clone the repo and generate CSV files:
   npm install
   node scripts/generate_data.js

2. Upload the CSVs (data/*.csv) to Google Sheets and create a Glide app from that sheet.

See GLIDE_SETUP.md for detailed instructions.
